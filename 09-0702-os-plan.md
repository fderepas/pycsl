# 09-0702-os-plan.md — plan to finish the remaining os proofs

**Date:** 2026-06-09
**Based on:** `09-0702-os-status.md` (status + the two remaining-proof buckets + the multi-session grind).
**Goal:** drive the os to **0 unproven goals** and **eliminate the codec round-trip axioms**
(`i18`, `i1a1`), leaving only the permanent `Bitmap` bitwise axiom — keeping os green at every step.

---

## 0. Success criteria

1. **Bucket A:** the **23** disk-mutating-syscall body-VCs proven → os unproven count **23 → 0**.
2. **Bucket B:** the codec round-trip is **proven inline** (SMT), so `#@ proof … i18.round_trip` (×2) and
   `… i1a1.round_trip` (×6) are **replaced by `#@ uses <proven-lemma>`** and dropped from the TCB.
3. **Permanent:** `Bitmap.bit_and_one_in_zero_one` stays a cross-validated axiom (genuine case-1).
4. **Invariant throughout:** os never regresses below its current proven count; corpus byte-clean; os
   `formal_0001` 18/18; doc-coherency + stdlib-coverage green.

The two buckets are **independent** and run on parallel tracks; B is the harder (proof-cost) track and
gets most of this plan.

---

## 1. The decisive lever (refines status §4.1): codec file-separation = modular verification, no new tool

The status doc named "modular verification of free functions / separate compilation" as the lever that
turns the aggregate wall into N cheap standalone proofs. **It is achievable now, by file layout —
because PyCSL's import resolver already emits an imported function as a contract-only `val` stub**
(`pycsl.py::_inject_functions`, "trusted stubs") and **Track B already lets that stub carry a narrow
interface** (`b3d65d1`).

**Plan:** extract the codec into its own module `pure_lib/os/codec.py`:
- the byte leaves (`_pack/_unpack_uint{16,32}_be`),
- `_pack_inode` / `_unpack_inode`, `_pack_direntry` / `_unpack_direntry`, `_pad_name`,
- and a **round-trip `#@ lemma`** (`forall fields. valid ∧ ranges → unpack(pack(fields)) == fields`).

`codec.py` has a **minimal context** (no 131072-byte disk record, no 10 class invariants, no 50 sibling
syscalls, no Bitmap axiom) — exactly the context where `_unpack_inode` proved in **12 s** instead of
> 300 s. `UnixInodeFileSystem` then **imports** the codec; the import gives it the codec's **interface**
contracts (cheap), not the bodies. **Soundness:** `codec.py` is itself in the verification suite (its
own `--pycsl` run / formal test), so the bodies *are* verified — once, in the cheap context — and the os
*uses* the proven contracts. No `\trusted`, no TCB growth.

> This is the difference between the failed pass-2 (everything re-verified in the inflated
> `UnixInodeFileSystem` context, `c-impl.md §3c`) and an affordable one (each codec function verified in
> `codec.py`'s minimal context, the os importing contracts).

**Risk / first probe (G0a):** the **round-trip lemma over 18 fields** must itself prove in `codec.py`'s
minimal context. The uint round-trip lemma already proves (A-probe); the 18-field one is heavier but in
minimal context may be affordable. **Probe it first** — if it proves, the `i18` axiom is eliminable; if
*even in minimal context* it is intractable, `i18` stays a (now case-2-justified) axiom and we still win
on cost for the rest.

## 2. Track B — eliminate the round-trip axioms (the proof-cost grind)

### G0 — Codec module + the decisive probe  *(session 1)*
- **G0a [PROBE]:** in a scratch `codec.py`, give `_pack_inode`/`_unpack_inode` their rich value
  contracts (length + 18 field values, **unrolled** loops, **specific** per-byte requires — the two
  pass-2 fixes) and state the round-trip as a `#@ lemma`. **Gate:** the lemma proves in minimal context
  (target < 120 s). *Decision point:* proves → continue; intractable → keep `i18` axiom, skip to §2-G4
  for the rest (still extract the codec for the cost win).
- **G0b:** create `pure_lib/os/codec.py` for real: leaves + inode/direntry codec + the round-trip
  lemma(s). Each function gets a **rich definition** + a **narrow `#@ interface`** (Track B): the
  interface is what the os imports (e.g. `_pack_inode` interface = `\length==64` + `∀i<64 bytes`;
  `_unpack_inode` interface = the 18 field-range ensures + the specific byte requires). **Gate:**
  `codec.py` proves standalone; corpus byte-clean.
- **G0c:** `UnixInodeFileSystem` imports the codec from `codec.py` (replacing the in-file definitions).
  **Gate:** os generates; os holds at its current count (the codec is now imported contracts).

### G1 — Region byte-invariant + the disk-read chain  *(session 2)*
- Add the **region byte-invariant** `∀i∈[512,2560). 0≤disk[i]≤255` to `UnixInodeFileSystem`
  (validated affordable by 0663/0664). Make `_read_inode` **supply the 64 byte-bounds** to the imported
  `_unpack_inode` interface — instantiating the region invariant at the read slice (likely needs
  specific extraction or a tiny bridging lemma `slice-of-region-is-bytes`).
- **Gate:** `_read_inode` proves; a disk-read inode's 18 field ranges are available from `_unpack`'s
  imported ensures. **Risk rule:** the invariant breaks all inode-region writers at once — so G1 must be
  landed *together with* G2 (the writers) before any full-os gate, or held on a branch.

### G2 — `_write_inode` requires + per-syscall discharge  *(session 2–3)*
- `_write_inode`: add the **18 range requires** (C1 — proven one-hop); its imported `_pack_inode`
  interface (bytes) makes the blit **preserve** the region invariant.
- `__format_disk`: source bytes into the inode region (from the byte-ensuring `_pack_inode`).
- Per-syscall discharge of `_write_inode`'s 18 requires:
  - **literal** inodes (`sys_mkdir`, `sys_creat`): trivial (proven in C1).
  - **disk-read** inodes (`sys_chmod`, `sys_write`, …): from `_unpack`'s imported field-range ensures (G1).
  - **computed mutations** (`inode[0]=new_size`, `inode[7]=_now()`, `inode[8+k]=p_block`): from
    `new_size ≤ disk_size = 131072 < 2³²`, `_now()` bound, `_alloc_block`'s contract (validated by 0662).
- **Non-inode writers frame:** bitmap `[0,36)`, dir `[2560,3072)`, data `[3072,…)` — all outside
  `[512,2560)`; disjointness discharges from existing block/offset bounds.
- **Gate (per method):** each syscall `--fun` proves under the raised budget.

### G3 — Full-os integration: drop the `i18` citation  *(session 3)*
- Replace `#@ proof rocq/lean UnixFs.Struct.i18.round_trip` on `_read_inode`/`_write_inode` with
  `#@ uses <codec round-trip lemma>` (imported from `codec.py`).
- **Gate (the decisive one, ~20 min):** full os run — **holds at 23 (or better), `i18`-axiom-free**;
  formal_0001 18/18; corpus byte-clean.

### G4 — Direntry round-trip: drop the `i1a1` citation  *(session 4)*
- Same chain for the **directory** codec (`_pack/_unpack_direntry`, `>H30s`, 30-byte name): a
  representation/byte invariant on the directory block `[2560,3072)`, the direntry round-trip lemma in
  `codec.py`, replace the **6** `i1a1` citations with `#@ uses`.
- **Gate:** full os — `i1a1`-axiom-free; os ≤ 23.

**End of Track B:** os SMT-proven except `Bitmap`; TCB shrinks from 3 axiom families to 1.

## 3. Track A — the 23 body-VCs (leaf-first, parallel)  *(interleavable, own track)*

The 23 are the disk-mutating syscalls' (`mkdir`/`makedirs`/`unlink`/`access`) body-VCs (Type-invariant +
bounds + array-creation over the disk). Per `os-bodyvc-spec.md` + the leaf-first doctrine:
- **A1:** group the 23 by failing VC kind (`--fun` each disk-mutating syscall; bucket: bounds / array-
  creation / type-invariant / postcondition).
- **A2:** fix bottom-up — give the foundational helpers (`_alloc_block`, `_alloc_inode`, `_dir_find_*`)
  the **value contracts** the syscalls need (bounded results), then the mid composers, then the syscall
  body-VCs. **Compose, don't re-derive** (the cheapest SMT escape).
- **A3:** the region byte-invariant + codec separation from Track B *help here too* (cheaper inode
  reasoning), so sequence A after G0–G2 where it overlaps.
- **Gate:** unproven count strictly decreases each session; never regress.

## 4. Cross-cutting: the time budget + gates

- **Budget (status §4.1 lever 1):** raise the os module's `--timelimit` (30 s → 120–300 s) for the
  codec-bearing proofs; add a second prover (Z3/CVC5 beside Alt-Ergo); use more cores for split-VC.
  *But* the **dominant** lever is G0 (minimal-context codec), not raw time.
- **Per-session gate cost:** G0/G1/G2 iterate with fast `--fun`/standalone proofs (sec–min); **G3/G4
  cost ~20-min full-os runs** — budget several per integration session.
- **os-green discipline (hard rule):** every committed state has os ≥ current proven count. Mid-refactor
  states that break os (e.g. region invariant before its writers) are held on a branch and merged only
  when the full-os gate passes.

## 6. Decision points (where the plan branches)

1. **G0a fails** (round-trip lemma intractable even in minimal context) → keep `i18`/`i1a1` as
   case-2-justified axioms; still extract the codec (cost win) and pursue **Track A only**. os gains the
   23 but keeps 2 axiom families.
2. **G1 caller byte-bounds too costly** (instantiating the region invariant at `_read_inode`) → introduce
   a small `#@ lemma region_slice_is_bytes` proved once, cited at `_read_inode` (a contained, cheap fix).
3. **Raw budget insufficient even with G0** → invest in the *real* separate-compilation tool feature
   (verify a module once, import a narrowed contract — `try.md §7`), generalizing G0's file-separation
   into a first-class mechanism. This is the fallback if file-layout separation proves too coarse.

## 7. One-line plan

Extract the codec to a minimal-context `codec.py` (verified once, fast, with a **proven** round-trip
lemma + Track-B interfaces the os imports), add the region byte-invariant + `_write_inode` requires so
disk-read/computed/literal inodes all discharge, then drop the `i18`/`i1a1` citations for `#@ uses` and
gate the full os — turning the aggregate proof-cost wall into bounded standalone proofs; run the 23
body-VCs as a parallel leaf-first track; keep `Bitmap` as the one permanent axiom; os green at every step.
