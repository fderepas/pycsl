## Part 2 — What needs to be done to finish all `os` system calls

"Finished" has **three bars**, at very different completion levels:

- **Bar 1 — structural/safety:** every syscall body proves (no SMT residual).
- **Bar 2 — zero-TCB (extreme rigor):** no `\trusted reviewer` directives; the TCB is
  the cited, dual-prover cross-validated axiom set only.
- **Bar 3 — functional consequence:** each syscall has a proven setup→operate→observe
  formal test (not a return-code assertion, not a simulation).

### Current state (verified 2026-06-17)
- `__init__` gate **1159/0 green**; body gate **2016 Valid / 8 residual**.
- TCB: **8 `\trusted reviewer` directives** (6 `dirscan-fidelity`, 2
  `fd-resolution-fidelity`) **plus** the cited `Bitmap` axiom family.
- Formal tests: essentially all syscalls covered; `chmod`/`truncate` PARTIAL;
  reopen-by-name round-trip open.

### A. Body-gate SMT residuals (8 → 0)
| Residual | What it needs | Difficulty |
|---|---|---|
| `sys_rename` ×2 | A different prover, a restructured proof, or composing its *already* Rocq+Lean cross-validated presence/absence lemmas in-context. **The reviewer-trusted `_rename_swap` is OFF THE MENU** (doctrine). | Hard — proven e-matching divergence |
| `_now` ×1 | Rework the line-436 byte-range class invariant (a trivial `\result>=0` OOMs under the full axiom set) or a targeted trigger. | Hard (touches every disk write) |
| `_unpack_direntry` ×2 | A **directory-region byte-range invariant** maintained by every disk mutator — a 2-clause leaf precondition only *relocates* the residual to `_read_directory` (uncovered region `[2560,3072)`). Flows from **Gap 5**. | Medium, but Gap-5-bound |
| `sys_write` ×3 | Nothing per-method — proves **400/0 in `--fun` isolation**; full-file aggregate E-matching noise only. | Cosmetic / non-issue |

### B. TCB debt (8 `\trusted` → 0) — the extreme-rigor bar

| `fd-resolution-fidelity` ×2 (`_check_perm`, `sys_readlink`) | Not yet investigated — the no-ENFILE / perm-resolution direction. Likely the same class. | Untried; logged GAP |

### C. Functional-correctness gaps (Bar 3)
| Gap | What it needs |
|---|---|
| `chmod` / `truncate` PARTIAL | A public **mode/size accessor** (none exists — `sys_stat` returns only the inode number) + str/int path consistency + a MODE/size codec round-trip rung + `sys_*` consequence ensures + a new public observer API + the formal test. |
| **reopen-by-name** content/size round-trip | Data-block recovery across close/open; `read` returning **content** (it returns a count today); write count `==` (not `<=`); reopened size pinned. The **on-fd** round-trip is already proven (`formal_os_content`). |
| **multi-block content** (Phase 2) | Resolve the loop content-`∀i` divergence (writes/reads beyond one 512-byte block). |

### D. The keystone — Gap 5 (directory name bytes unmodeled)
**Gap 5 is the single root blocker behind most of the hard remaining work.** Modeling
the directory name-byte field faithfully — a cross-validated byte↔string codec for the
30-byte name field — would unlock, in one stroke:
- the **byte-decode definitional axiom** that retires the **6 `dirscan-fidelity`**
  trusts (B),
- the **directory-region byte-range invariant** that closes **`_unpack_direntry`** (A),
- **by-name resolution** for the **reopen-by-name** round-trip (C),
- and plausibly part of **`sys_rename`**'s name-resolution composition (A).

It is a substantial model extension and a **human-gated** decision (it adds modeling
surface and, if any axiom is needed, a cross-validated TCB item).

### Prioritized plan
1. **Gap 5 — model the directory name-byte codec (cross-validated).** The keystone;
   unlocks B-dirscan, A-`_unpack_direntry`, and C-name-resolution at once.
2. **Retire the 6 `dirscan-fidelity` trusts** by defining `slot_inode`/`slot_name`/
   `dir_lookup` over disk bytes (definitional, Rocq+Lean), and **close
   `_unpack_direntry`** via the directory-region byte-range invariant.
3. **`chmod`/`truncate` accessors** → close the two PARTIAL syscalls (Bar 3).
4. **reopen-by-name + multi-block content** → the functional frontier.
5. **`sys_rename`, `_now`, `fd-resolution-fidelity` ×2** → the residual hard items
   (different prover / invariant rework / kernel proof); some may remain logged GAPs
   even under best effort — that is acceptable and honest, never closed by trust.
6. **`sys_write` ×3 aggregate noise** → accept the per-method metric, or tame the
   cross-axiom E-matching (cosmetic).

### The honest bottom line
- **Bar 1 (structural/safety): effectively done** — 2016/8, where the 8 are ~5 genuine
  hard residuals + 3 aggregate-noise non-issues.
- **Bar 2 (zero-TCB / extreme rigor): NOT done** — 8 `\trusted reviewer` directives
  remain; the 6 `dirscan-fidelity` ones are a **confirmed structural wall blocked by
  Gap 5**, not a quick fix.
- **Bar 3 (functional): partial** — the on-fd content round-trip is proven; by-name,
  multi-block, and the `chmod`/`truncate` consequences remain.
- **The single highest-leverage move is closing Gap 5.** Most of the genuinely hard
  remaining work (the dirscan TCB debt, `_unpack_direntry`, by-name resolution) flows
  from it. Until then, those targets stay honestly logged as GAPs — never retired by a
  trusted swap, never weakened to pass.
