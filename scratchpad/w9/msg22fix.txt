THE FIX IS THE COMMENT'S OWN LICENCE TURNED INTO A MACHINE CHECK. A field
the emitted record DECLARES is present, so `getattr(o, "f", d)` IS `o.f`
and lowers as the real read. `_emitted_record_field_labels` is the
per-class oracle; the pre-existing `_all_record_fields` branch is a UNION
over every class AND is gated on `@mutable_state`, which is exactly why
the corpus sat outside it. ABSENCE still takes the default — a name the
record does not declare is genuinely missing at runtime too — so the 20
`self.<runtime cache>` sites the census found are untouched, and are now
correct BY CHECK rather than by luck.

`array emit_ir` and both the int-truthiness form `x <> 0` and

fail-closed doing its job -- an erasure hides a TYPE ERROR as much as it
hides a value, so closing the erasure uncovers it, and the two must land
in the same increment. Respelled with the shape the adjacent `orelse`
block already used: bind the `to_dict()` comprehension, test that.
`finalbody` is a REQUIRED dataclass field of TryStmt, so the old
`getattr` default was pure defensiveness; computed once and reused by the
`finally` emission, so the method got shorter.
