Root cause of F1 / F2: src/pycsl/frontend/ir_resolve.py::_inject_functions (shared by the direct, wildcard
and module-qualified resolvers). It "insert[s] each dependency stub ... if no function of that name is
present yet", so a dependency function whose name is already taken (by a local def, or by another
dependency) is silently skipped. The qualified call then lowers to the bare name. This is exactly the
"two definitions, one WhyML name" defect that #620 targets, at a point #620 never sees. Suggested fix: in
_inject_functions, refuse when the name exists and the existing entry is not that same dependency
function (compare the `_r143_dep_file` tag and the name).
