Notes on O2-O5. A transitive in-file callee (BFS in _process_dependency) gets the same refusal as a function
the program called itself. The stubs are trusted `val`s and only their contracts are used, so a callee that is
used only inside a body and appears in no contract does not need a unique WhyML name. Suggested narrowing:
- when the clashing entry is a transitive-only callee that no injected contract references, do not refuse.
  Skip it as base did, or better, do not inject it at all.
- R3b shows that inlining can splice such bodies (`apply_inline_globals`). Narrowing is therefore sound only if
  inlined bodies are not admitted when a callee name is shadowed.
On O1: the star import sits BEFORE the local def, so CPython's binding is the local def and base was faithful.
Refusing it is fail-safe, but it is new.
