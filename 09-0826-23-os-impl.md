CompCert/seL4 effort.
**Two corrections to the strategy this doc bakes in:**
1. **Tier 1 ("totalize the codec leaves") is replaced by a faithful path.** The real `_pack_uint16_be`
   (`bytes([v//256, v%256])`) *raises `ValueError`* for `v > 65535`; declaring it "requires only
   `\valid`" misrepresents the codec. The faithful discharge of its range requires is a **field-range
   representation invariant** that *supplies* the ranges, never a total leaf.
2. **Clearing the 23 and removing the i18 axiom are ORTHOGONAL.** This is the most important correction.
   See §1.

## 1. The decisive clarification: two orthogonal goals

The strategy bundles "clear the 23" with "remove the requires-bloat and the axiom." Read from the code,
these are **independent**:

- **Goal A — clear the 23.** Each syscall's *postcondition* is a return-code disjunction
  (`\result == 0 or \result == -1`), and every `return` is a **literal** — so the postcondition is
  trivially true with **zero disk-content reasoning**. The committed `_write_inode` requires only
  `\valid(inode, 18)` + `inode_num` bounds (it does **not** require the 18 field ranges), so the
  syscalls' callee-precondition body-VCs are light. The 23 fail purely for **SMT-tractability** —
  the codec's quantified byte-index contracts crowd the solver's context, and long guard-heavy bodies
  generate many sub-goals. **Goal A is context engineering: thin the context, prove standalone. It does
  not touch the codec round-trip or the i18 axiom at all.**
- **Goal B — remove the i18 axiom (TCB reduction).** This is about the codec *round-trip*
  (`unpack(pack(x)) == x`), which the i18 axiom currently supplies. It is **not needed to clear the 23**
  (their postconditions are content-independent). It is a separate, *optional* goal, already at a sound
  resting point (the cross-validated axiom).

**Consequence:** the realistic path to "23 → 0" is **Goal A only** (T0 + T2 + T3, keeping the axiom).
Goal B's faithful field-range chain (the proof-cost-bound part) is **off the critical path** for the 23.
This is cheaper and lower-risk than the strategy's bundled framing.

## 2. Goal A — clear the 23

### T0 — codec is a *direct* shallow neighbour (never `--deep`)

`UnixInodeFileSystem.py` imports `.codec`, but `os/__init__` reaches the codec only *transitively*
(`os/__init__ → UnixInodeFileSystem → .codec`); resolving it needs `--deep`, which pulls the **entire
transitive closure** (clock, world, path) into one module and makes the per-goal quantifier-instantiation
(E-matching) search catastrophic (the full os proof did not finish past ~23 min). Fix: make codec a
**direct** dependency of `os/__init__` so the ordinary shallow resolver injects it as a single `val`
stub carrying only its `#@ interface`, and **never** pass `--deep`.

- **Edit:** in `pure_lib/os/__init__.py`, after `from .UnixInodeFileSystem import UnixInodeFileSystem`,
  add `from .codec import (_pack_uint16_be, _unpack_uint16_be, _pack_uint32_be, _unpack_uint32_be,
  _pack_inode, _unpack_inode)`. (These resolve as direct-dependency `val` stubs; their bodies are
  verified once in `codec.py`, so no body-VCs enter the os proof.)
- **Gate:** `pycsl pure_lib/os/__init__.py` (no `--deep`) **completes** and holds at the current
  unproven count; the os `val _pack_inode` shows only `\length == 64` (the interface). Commit the codec
  import (`UnixInodeFileSystem.py` + `os/__init__.py`) once this gate is green.
- **Measure:** record the wall-clock and the unproven count. T0 alone may already drop some of the 23
  whose only friction was the codec contracts crowding the context.

### T2 — `#@ interface` on the disk helpers

A syscall's body-VC that calls `_dir_lookup`/`_read_inode`/`_write_inode`/`_alloc_*`/`_write_entry`/
`_check_perm` should see each as a *narrow* contract (return-code range + type-invariant preservation),
not its internals — so the solver discharges the callee precondition and return-code propagation against
a handful of thin facts instead of instantiating the helper's full body-derived contract.

- **Edit:** give each disk helper a narrow `#@ interface` (Track B). Examples:
  `_alloc_inode` / `_alloc_block` → `#@ interface ensures \result == -1 or (0 <= \result and \result <
  N)`; `_dir_lookup` → `#@ interface ensures \result == -1 or (0 <= \result and \result < 32)`;
  `_dir_find_free` → `#@ interface ensures \result == -1 or (0 <= \result and \result < 16)`;
  `_write_inode` / `_write_entry` / `_write_directory` → `#@ interface assigns self.disk` +
  `#@ interface ensures True` (return-code-irrelevant; the only fact callers need is the frame +
  invariant preservation).
- **Soundness:** each `#@ interface` is a *proven weakening* of the helper's definition (the narrowing
  VC discharges in the owning unit); a helper whose interface claims more than its definition proves is
  rejected (fail-loud).
- **Gate:** each helper proves (definition + narrowing VC); corpus byte-clean for files without
  `#@ interface`.

### T3 — standalone-prove each `sys_*`, then `no_inline`

With T0+T2 thinning the context, prove each of the 23 syscalls *standalone* in the os module
(`--fun unixinodefilesystem__sys_<name>`). Per §1 the return-code goal is trivial and the body-VCs are
bounds arithmetic + light callee preconditions + length-preserving slice-writes — they should discharge
in a thinned context. For each `sys_*` that proves standalone, add `#@ no_inline` so the `os.*` wrappers
(`os.mkdir`, `os.makedirs`, …) reuse its contract instead of re-proving the inlined body.

- **Soundness gate (critical):** `#@ no_inline` is sound only because the `sys_*` proves its *real*
  contract standalone — confirm each before reusing it (no false-green where a wrapper passes only
  because the body was elided).
- **Gate:** each `sys_*` `--fun`-proves; the full os proof's unproven count strictly decreases; commit
  per syscall (or per small group) keeping os green.
- **Measure & split:** record which syscalls clear. *Literal-inode* syscalls (`sys_mkdir`, `sys_creat` —
  build an 18-element literal inode, in range by construction) discharge `_write_inode`'s requires from
  the literal and should clear first. *Read-then-mutate* syscalls (`sys_unlink`, `sys_chmod`,
  `sys_link`, `sys_write`, …) read an inode and mutate a field; with the committed light `_write_inode`
  (no field-range requires) they too clear on the return-code/body-VC axis — but this is the place to
  watch for the aggregate proof-cost (§4): a long body in the still-nontrivial os context may overrun
  its per-goal budget.

### T4 — scoped abstraction barrier (contingency only)

For any *measured* straggler — a syscall whose body-VC the solver cannot get within budget even in the
thinned context — introduce an abstract inode/fd/dir *view*: prove the return code over abstract maps,
and confine the disk-byte VCs to the boundary helpers. Highest cost (needs a logic-view of the codec).
Apply **only** where T0–T3 leave a hard goal; never wholesale. This stays PyCSL-native (Why3/SMT), not
CompCert.

## 3. Goal B — remove the i18 axiom (separate, optional, faithful)

This is **not required for the 23**. Pursue it only as a deliberate TCB-reduction effort.

### T1′ — faithful field-range discharge (replaces the strategy's Tier 1)

Keep the codec leaves **faithful** (their real range requires; the leaf genuinely raises out of range).
To let `_write_inode` prove the round-trip *without* the axiom, the read inode's fields must be
known-in-range — supplied, not narrowed away:

- **Disk-byte representation invariant** on the inode region: `#@ class invariant \forall i; (512 <= i
  and i < 2560) ==> (0 <= self.disk[i] and self.disk[i] <= 255)`. Validated affordable (a region
  byte-invariant survives slice writes in seconds — drivers 0663/0664); maintained only by the
  inode-region writers (`_write_inode`, `__format_disk`), since every other write (bitmaps `[0,36)`,
  directory block 5 `[2560,3072)`, data `[3072,…)`) is outside `[512,2560)` and preserved by frame.
- **`_unpack_inode` field-range ensures** (`0 <= \result[k] <= MAX_k`) — provable from the leaf ensures
  given the slice bytes ∈ [0,255] (use **specific** per-byte requires, not a quantified `\forall i<64`,
  which times out on instantiation). So `_read_inode`'s result has in-range fields.
- **Field-range representation invariant** on a typed inode supplies `_pack_inode`'s real range requires
  at the call site, and survives computed mutations (`inode[0] = new_size` with `new_size ≤ 131072 <
  2³²`, etc.) — drivers 0661/0662.
- **The axiom itself** is then removed by the **inline round-trip**, which proves in ~42 s in the
  separated `codec.py` (driver 0665): replace the `#@ proof rocq/lean …i18.round_trip` citation on
  `_read_inode`/`_write_inode` with the proven property.

### T5 — Rocq durability only

If the inline round-trip is not pursued, keep the codec round-trip as the cross-validated axiom (the
accepted resting point), preferring a kernel **replay** over an unverified `axiomatize` to shrink the
TCB. Rocq/Lean are used **only** for this one foundational lemma — never as the proof engine for the 23,
never for extraction.

## 4. Sequencing, measurement, and the honest risk

1. **T0 (finish + commit) → measure.** Cheap, certain; thins the context; may clear several of the 23.
2. **T2 (helper interfaces) → measure.** Cheap; thins further.
3. **T3 (standalone-prove + `no_inline`), syscall by syscall → measure after each.** Commit per syscall,
   os green throughout.
4. **T4** only for a measured straggler.
5. **Goal B (T1′/T5)** is independent and optional — schedule separately; it does not gate the 23.

**The one real risk — aggregate proof-cost — is confined to Goal B and any T4 straggler.** A codec
function proves *standalone* in seconds but is slow *in the full module* (`_unpack_inode`: 12 s alone,
> 300 s in-file), and the cost compounds across a dependency chain. Goal A avoids this entirely (the 23
do not touch the codec round-trip or the field-range chain); Goal B walks into it deliberately, which is
why Goal B is optional and the i18 axiom remains a sound fallback. **Measure after every tier — reason to
design the tier, run it to decide the next.**

## 5. Gates / verification

- **T0:** `pycsl pure_lib/os/__init__.py` (no `--deep`) completes; unproven count ≤ current; os
  `val _pack_inode` carries only the interface; corpus byte-clean; commit.
- **T2:** every helper's definition + narrowing VC proves; a helper with an over-claiming `#@ interface`
  is rejected (fail-loud); corpus byte-clean for untouched files.
- **T3:** each `sys_*` `--fun`-proves standalone before `no_inline`; full os unproven count strictly
  decreasing; os `formal_0001` 18/18; doc-coherency green; commit per syscall.
- **Goal B (if pursued):** `pycsl pure_lib/os/codec.py` proves (round-trip ~42 s); the disk-byte +
  field-range invariants discharge `_pack_inode`'s real requires (0661–0665 pattern); dropping the i18
  citation keeps os ≤ its count; TCB ledger records the axiom removed.
- **End state (Goal A):** os unproven count **23 → 0**, the i18 axiom *kept* (accepted), no CompCert/seL4
  machinery, the pipeline unchanged (Why3 + Alt-Ergo/Z3).

## 6. Out of scope

The direntry codec (`_pack_direntry`/`_unpack_direntry` — same separate-and-interface pattern, fold in
after the inode case); rich functional postconditions beyond return codes (e.g. "`mkdir` creates a
type-2 inode" — those want Track C's abstract view, a separate later goal); changing Why3 or the SMT
solvers; full os extraction (the CompCert/seL4 hammer — explicitly rejected: the 23 are SMT-closable).

> **In one line:** clearing the 23 is **context engineering** — make the codec a *direct* shallow
> neighbour so it never floods the module under `--deep` (T0), give the disk helpers narrow `#@ interface`
> contracts (T2), and standalone-prove + `no_inline` each syscall in the thinned context (T3), with a
> scoped abstraction barrier (T4) only for a measured straggler — all PyCSL-native, the i18 axiom kept;
> the strategy's Tier 1 (totalize the leaves) is unfaithful and, in any case, *orthogonal* to the 23,
> so the requires-bloat/axiom-removal work (the proof-cost-bound part) is the separate, optional Goal B
> done faithfully via a field-range representation invariant and the inline round-trip — never a total
> leaf, never extraction.
