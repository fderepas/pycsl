# getting-better/

Improvement proposals filed by the `test-supervise-sl` / `formal-test-sl` loops:
PyCSL or tooling **features** that would make writing or proving formal tests
easier — an ergonomic gap surfaced during a run.

- One concern per file.
- Filename: `YYYYMMDD-hhmm-simple-name.md` (e.g. `20260616-1547-handle-reference.md`).
- These are **proposals**, not accepted knowledge. When a feature lands, fold the
  durable lesson back into `config/skills/pycsl-monitoring/` (via Gate S) and the
  proposal file can be archived.

Suggested body shape: **What's painful now** · **Proposed feature** · **Why it
helps the loop** · **Rough effort / risk**.
