## The defect (one class)
Inside a `@mutable_state` class a value typed as an IR node (`emit_ir`) is read through projector functions of the
emit_ir theory. Every projector was total with a PLACEHOLDER default: `IrOther ""` for a node child, `""` for a
string field, and the truthiness of a projected child was the literal `true`. After a test that pins the receiver's
class, a read the class's constructor does not carry (or a read routed to ANOTHER class's projector) is the
placeholder, so the model decides a branch CPython takes:
- #596 no arm for the class (IfExpr `.test`, Forall/Exists `.body`, DictComp/MapValueIs `.value`, a gated clause
  constructor that is off in the file, every StmtIR receiver: `x.kind == "Assign"` admits only `IrOther "Assign"`);
- #586 node fields shared across classes routed to IrBinOp's `left_of`/`right_of` (`.dict/.key/.head/.tail/.left/
  .right/.lo/.hi/.size/.default`, the swap-family handler tables), dict-view `index` to the Subscript `sindex_of`;
- #587 string fields routed to one class's `op_of`/`name_of`/`func_of` (`.op` of UnaryOp, `.name` of InGlobals,
  `.var` of ArrayLen, `.ctor` of CtorTest, `.label`, `.base*`, `.arr`, `.func` of the `IrCallN` call; dict view
  `name`/`attr`/`field`/`func`/`ctor`/`op`);
- #588 `_to_bool` of a projected child decided `true`;
- #594 `child.value is None` on a raw `ast.stmt` (pyast_stmt walk) decided `false`.
