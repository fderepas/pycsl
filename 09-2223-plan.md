# 09-2223-plan.md — Breaking the composition wall: plan

*Self-contained plan, 2026-07-09. Companion and answer to the step-back brief `09-2223` ("A verifier
that cannot verify its own reflection: the composition wall"). Assumes its §1–§5 context: the certified
pointwise value model (`pyval`/`pydict`/`sdict` + `Phase2b_RecordVal`), the solved char-string and
closed-key-record faces, the 70-method census (mirror-only defensive projection → **0 net-new**), the two
measured partial impossibilities (corpus-facing rewrite byte-diff-unsafe; one-theory-per-module `size`
collision), the 3-axiom ledger, and the type-safety+frame+termination-only contract. Discipline carried
from `value-model-wall-stand-alone-plan-2.md`: spike-gated commitments, measured acceptance only
(no asserted VC profiles), yields counted once.*

**Thesis.** The brief's crux (§2: "the weak contract starves the solver of value invariants") needs one
refinement, and the refinement dissolves most of the wall. A `requires True / ensures True / assigns F`
whole-body VC needs **no value facts anywhere**: statement by statement it needs (i) well-typedness of
each projection, (ii) a variant per loop, (iii) frame containment. If composition fails, one of two
*non-value* inputs is missing: **type flow across the reflective boundary** (a pointwise cast yields
`pyval`, but every consumer — `_collect_calls`, `_expr_to_whyml`, the IR-node ADT world — expects typed
values, so casts inside the fold type-clash at every use), or **frame preservation through loops**
(without per-loop preservation invariants, the frame half of the VC dies inside any iteration,
independent of reflection). Both missing inputs are **syntactically synthesizable** — derivable, not
inferred; no Houdini search, no refinement engine, no ledger cost. The plan is three moves — **M1** a
namespacing fix that converts the second "partial impossibility" into engineering, **M2** one certified
boundary decoder replacing N casts through the fold ("parse, don't validate"), **M3** synthesized
`loop assigns` frame invariants — gated by one cheap falsifying spike (**S-dec**). The 70-census result
(0 net-new) is *predicted* by this diagnosis, not contradicted by it: the census refuted **pointwise
casts**, not the boundary architecture.

## 1. M1 — The `size` collision is namespacing, and it is the enabling step

§5.2 presents the `pyval`-vs-IR-node-ADT `size` collision as a measured boundary. Re-classify: a *name*
collision is emission engineering, not semantics. Resolutions, in preference order:

1. **Qualified use** — emit `use PyValTheory as PV` and reference `PV.size` (Why3 supports qualified
   imports and clone-with-renaming natively);
2. **Rename the certified measure** to `pv_size` in the theory and mechanically re-run the Rocq/Lean
   certificates (a rename does not change any proposition; `Print Assumptions` / `#print axioms` re-check
   is the whole obligation).

Why this is first: the module that currently *cannot exist* — one hosting **both** the `pyval` theory and
the IR-node ADT — is exactly the module the whole solution lives in. The reflective→typed boundary (M2)
**is** a two-theory module. Until M1 lands, no decoder can even be emitted.

**Acceptance.** A spike `.mlw` containing both theories type-checks and its (empty) VCs run; corpus
byte-diff-0 (preamble emission is mirror-gated); ledger unchanged (a rename co-lands the re-checked
certificates).

## 2. S-dec — the decoder spike (the falsifier; days, not weeks)

**Question.** Does hoisting the reflective→typed conversion to a single boundary unblock the composition,
or is the wall genuinely monolithic?

**Build (minimal).** M1's two-theory module + `decode_func : pyval → option ir_func` for **only the
fields B-comp touches** (`name`, `trusted`, `abstract`, `contracts.ensures`, `body`) +
`decode_func_list : pyval → list ir_func` (malformed elements skipped). Lower B-comp's first statement
through it; leave the rest of the body as-is. Whole-body run.

**Outcomes (each one sharpens the campaign):**
- **Stalls at the first statement even with the decoder** → the diagnosis here is wrong; the brief's
  monolithic-composition framing wins; B-null is argued from this measurement, and the survey question in
  the brief's §6 stands as posed.

- **Advances past the loop, dies elsewhere** (set-algebra chain, `sorted`, record return) → the residual

  discharge table updated by measurement.

Per plan-2's C4 lesson: the spike's verdicts are the only admissible evidence; nothing in §5's table is
claimed before this run.

## 3. M2 — One certified boundary decoder, not N casts through a fold

**Principle ("parse, don't validate", King; verified-deserializer discipline, EverParse's shape minus
F\*).** The composition collapses if the reflective world is exited **once**, at the top of the method,
rather than crossed at every projection inside the fold. Gradual-typing SOTA says the same thing from the
other side: cast *composition* through a loop is the known pathology; hoisted, monotonized coercions —
i.e., exactly one cast — are the known fix. The brief's §6 anchor "the open part is composition of casts
through a fold" is answered by **not composing casts**.

**Mechanism.**

```whyml
(* total, defensive; malformed nodes -> None / skipped; only touched fields decoded *)
let rec decode_func (v: pyval) : option ir_func
  variant { PV.size v }
= match v with
  | PDict d ->
      Some { fn_name     = (match slookup "name" d with Some (PStr s) -> s | _ -> "");
             fn_trusted  = (match slookup "trusted" d  with Some (PBool b) -> b | _ -> false);
             fn_abstract = (match slookup "abstract" d with Some (PBool b) -> b | _ -> false);
             fn_ensures  = decode_ensures (slookup "contracts" d);
             fn_body     = decode_body    (slookup "body" d) }
  | _ -> None
  end
with decode_func_list (v: pyval) : list ir_func
  variant { PV.size v }
= match v with
  | PList l -> filter_some (map_decode l)   (* malformed elements skipped *)
  | _ -> Nil
  end
```

- **After the boundary, the method is verbatim-typed.** `f["name"]` lowers to the accessor `fn_name f`
  (total on decoded values *by construction*); the nested `f.get("contracts",{}).get("ensures")` lowers to
  `fn_ensures f`; sibling calls receive the ADT they already expect. The 70-census failure mode —
  `pyval` leaking into typed consumers — cannot occur, because `pyval` does not survive the first
  statement.
- **Verbatim-source constraint respected.** This is a *lowering* decision for the reflective read, not a
  source change; defensiveness (malformed dict → default where Python would `KeyError`) is admissible
  under the contract, identical in kind to every landed defensive totalization.
- **Certification cost: zero new shapes.** The decoder is a catamorphism `pyval → ADT` — a **T1 instance**
  of the certified functorial-map family from `ir-traversal-residual-stand-alone-plan.md`, same structural
  `PV.size` variant, per-instance re-proof (generator stays out of the TCB). `pyval` is certified; the
  IR-node ADT already exists in emission; `option` exists. **Ledger holds at 3 with no new certificate.**
- **Scope.** Mirror-side only, behind the existing gate — §5.1's corpus-facing impossibility is untouched.

## 4. M3 — Synthesized loop frame invariants (`loop assigns` discipline)

For every loop in a mirror method, the emitter auto-derives preservation invariants from the declared
frame — deterministically, from syntax:

- for each self-state component `c` **not** in the method's `#@ assigns` and not in the loop's write set:
  `invariant { self.c = (old self.c) }` (equality preservation);
- for components that **are** written: the write-set containment invariant matching the `assigns` clause;
- loop-local accumulators (`counts`, `vcs`, …) appear only in their own write set.

This is ACSL's `loop assigns` / Dafny's loop-`modifies` discipline, and the first-order cousin of implicit
dynamic frames (Viper) — cited as the right relative, without importing a permission logic. It is the
classic Houdini *candidate family*, except no guess-and-check occurs because the candidates are **exact by
construction** from the `assigns` clause. Per-instance re-proof keeps synthesis out of the TCB: a wrong
invariant yields an unprovable instance, never a false proof. With ~90 self-state fields the emission is
verbose but mechanical — and it unblocks **every loop in every reflective method simultaneously**, not
just B-comp. (If VC size becomes a solver-budget problem, group untouched fields into a single
record-equality invariant `self.rest = old self.rest` per the record certificates — measured, not
presumed.)

## 6. B-null, narrowed (what honestly remains if/where the moves succeed)

Not the composition itself, but three named sub-classes, each closing as documented `TRUSTED(essential)`:

1. **Non-IR-shaped reflective dicts** — no ADT decode target exists, so no boundary can be drawn (the
   decoder needs a typed codomain; "reflect on arbitrary dynamic data" has none).
2. **Semantic-guard-dominated type-safety** — the recurring brick from both sibling plans: methods where a
   runtime comparison dominates a projection's safety; defensive decoding changes their shape. Detected
   mechanically (guard-dominance); closed per method by source normalization or documented trust.
3. **Frame-inexpressible siblings** — calls whose write effects cannot be stated in the current self-state
   model; M3 cannot synthesize invariants for frames the model cannot express.

And the standing, untouched impossibility: **§5.1 corpus-facing rewriting** — everything in this plan is
mirror-side. If S-dec's first outcome fires (stall despite the decoder), B-null re-expands to the brief's
original form, now with the decoder measurement as its strongest evidence.

## 8. Yield honesty and the dividend

The population is the ~70-method reflective census plus B-comp. The honest projection: M2+M3 attack the
two blockers the census found *composed everywhere* (typed-boundary absence; frame-through-loop), so the
expected unblock is a substantial fraction of that class — but per discipline the number is **produced by
re-running the census after M3**, not asserted here. Yields remain **counted once** across this plan and
the traversal/value siblings (the walker class appears in all three).

Bootstrap dividend: M2's decoders are the missing "verified deserialization of dynamic data into typed
values" capability for *user* programs; M3's loop-frame synthesis benefits **every** verified loop in any
user program with an `assigns` clause — both are user-facing features, not just self-verification tools.

## 9. One-paragraph brief (mirror of 09-2223 §6, answered)

*The solver was never starved of value invariants — a frame-only contract needs none. It was starved of
types across the reflective boundary and frames across loops, and both are derivable rather than
inferable. Fix the theory-hosting name collision (it is namespacing, not impossibility); exit the
reflective world exactly once per method through a certified total decoder `pyval → ADT` (a template
instance of the existing certified catamorphism family — no new shape, ledger at 3), so casts never
compose through the fold and every downstream projection is a total typed accessor; and synthesize
per-loop frame-preservation invariants deterministically from the `assigns` clause, Houdini-shaped but
search-free. The 70-census zero is consistent with this: it refuted pointwise casts, which leak `pyval`
into typed consumers — not the hoisted boundary. One cheap spike falsifies or confirms the whole
diagnosis at B-comp's first statement; if it falsifies, the brief's B-null stands with the decoder
measurement as its sharpest evidence, and if it confirms, B-comp discharges through mechanisms that are
each already in a solved class, leaving a narrowed, three-clause `TRUSTED(essential)` boundary —
non-IR-shaped reflection, semantic-guard-dominated safety, frame-inexpressible siblings — as the honest
residual of the composition wall.*
