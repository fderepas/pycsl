# 07-1839-plan — Implementation plan: introspection & metatypes

**Status:** Plan (what to change, in what order, behind which gate) — implements `07-1839-spec.md` (rev. 2).
**Date:** 2026-06-07
**Scope:** PyCSL tool (`src/pycsl`) — a Module4 dataflow pass + Γ/`τ`-tag resolution + CSL grammar +
Module5/6 emission — plus two pure_lib modules (`pure_lib/builtins`, `pure_lib/types_mod`). No
semantic edits to existing `pure_lib/`.
**Doctrine:** no-more-int / EXTREME RIGOR. The three-valued resolution (decided-true / decided-false /
unknown, **unknown is never emitted as a fact**) is the source-of-truth fail-safe: the only
acceptable failure is a loud one, never a wrong proof. Non-introspecting files emit byte-identical
WhyML (the regression gate). Each phase: reproduce → implement → gate (full `--pycsl` sweep clean +
WhyML byte-diff + traceability row + an **anti-unsoundness negative driver**).

This plan folds in the three review findings agreed on the spec (A/B/C below) as **resolved
decisions**, not open questions.

---

## 0. Resolved design decisions (from the spec review)

- **(A) `bool` collapses to `int` for introspection — no distinct `TAG_BOOL`.** Γ has `τ(bool)=int`
  (a *type-level* collapse, not just emission), so a bool tag cannot be derived from `τ`. Therefore:
  `\typeof(b)` → `TAG_INT`; `isinstance(b, int)` → **decided-true** (correct); but **`type(b) is bool`
  is Specified/unknown** (PyCSL cannot distinguish bool from int exactly) — it must NOT be
  decided-true *or* decided-false. The `\subtag` relation drops the `bool <: int` edge (there is no
  `TAG_BOOL`); this removes the §4.1↔§4.2 contradiction. Documented in the Soundness Ledger.
- **(B) `\typeof` is sound only on a *stable-`τ`* name.** A name retyped or assigned different `τ` on
  different paths has no single tag. So `\typeof(x)` is **decided only when `x` has one consistent
  `τ` across all its assignments/paths in the function**; otherwise → **unknown** (free symbolic
  tag). This is the metatype analogue of the scope-side path-sensitivity; it is a cheap per-name
  consistency check riding on the same Module4 dataflow (P3), not a separate pass.
- **(C) A dynamic `exec`/`eval` taints the scope dataflow.** Besides tainting `assigns`/HAPPY
  (worst-case mutator), a dynamic exec can inject arbitrary names → after it, **every `\in_scope(n)`
  decided-false is withheld** (membership becomes ≥unknown downstream). The dataflow models a dynamic
  exec as "havoc the binding set."

## P0 — Feasibility probe (GATE; hand-written WhyML, no emitter change)

The risky assumption here is not aliasing (as in 07-1705) but **`\subtag` modelling**: that a small
finite int-tag enum + an axiomatized `subtag` relation discharges `isinstance`-against-a-base-type in
SMT without trigger blowups, and that reflexivity + the is-a edges don't let a *false* `isinstance`
prove.

- **P0.1** Hand-write a `.mlw`: `type tag` enum (int constants), `predicate subtag tag tag` with
  axioms (reflexive; `int <: object`, `str <: object`, …; leaf types have no proper sub-tags), and
  prove: `subtag TAG_STR object` (true), `not (subtag TAG_STR TAG_INT)` (a leaf≠leaf is decided-false),
  `subtag a object` for all `a` (universal upper bound).
- **P0.2** Prove the **anti-unsoundness** shape: an `Any`-tagged value (free `tag`) makes
  `isinstance` *neither* provable nor refutable (the symbolic tail).
- **Acceptance:** `[PROVE]` P0.1 edges discharge in Alt-Ergo/Z3 < 1s each; `[PROVE]` P0.2 free-tag
  `isinstance` is independent (neither goal closes). If either fails, revisit the tag encoding before
  P4. Artifact: `docs/probes/07-1839-P0-subtag.mlw`.

## P1 — Three-valued core + grammar (LOW)

- **Files:** CSL grammar (`Module2_Parser.py`) — add the §6 keywords (`\in_scope`, `\in_globals`,
  `\has_attr`, `\scope_type`, `\typeof`, `\subtag`, `\is_callable`, `\code_argcount`,
  `\code_nlocals`) + nodes; a shared `Resolution` enum {decided_true, decided_false, unknown} used by
  Module4/5.
- **Rule:** an `unknown` resolution emits **nothing** (no axiom, no `true`, no `false`).
- **Acceptance:** `[review]` every new predicate has all three branches wired and `unknown` is
  provably non-emitting (grep the emitter: no path turns `unknown` into a fact); `[byte-diff]`
  files using none of the new keywords are byte-identical.

## P2 — Easy sound wins (LOW)

- **`globals()` / `\in_globals(name)`** — `collect_module_globals` → decided-true for a declared
  module name, **unknown otherwise** (open world: import/exec inject). Never decided-false.
- **Arithmetic builtins** `abs/divmod/pow/round/min/max/sum` — Modelled (pure arithmetic; mostly
  already exist — confirm and pin), `len` → existing `\length`.
- **Driver:** `[PROVE]` membership of a declared global; `[PROVE]` an undeclared name stays unknown
  (anti-unsoundness: the decided-false direction is withheld); arithmetic laws.

## P3 — Definite-assignment dataflow (MEDIUM-HARD; the scope-side fix)

- **File:** new analysis in `Module4_SemanticAnalyzer` (a real pass): for each program point, the
  must-be-bound set (assigned on **all** paths) and may-be-bound set (assignable on **some** path).
- **Resolution:** `\in_scope(name)` decided-true iff in must-set, decided-false iff **not** in
  may-set, else unknown. Handles `del x`, conditional assignment.
- **(C) dynamic-exec havoc:** a dynamic `exec`/`eval` in scope clears the *certainty* of the may-set
  downstream → `\in_scope` decided-false is withheld after it (only true via must-set-before-exec, or
  unknown). The dataflow marks a "binding set is open" flag post dynamic-exec.
- **`vars(obj)`/`\has_attr`** — class-field lower bound (Γ_c from `__init__` + method `self.f`
  scans); decided-true for an all-paths-assigned field, **unknown** otherwise (`hasattr` false is the
  unsound direction).
- **`\scope_type(name)`** — the name's `τ` only when membership decided-true.
- **Drivers:** `[PROVE]` all-paths-assigned ⇒ `\in_scope` true; **`[PROVE]` (anti-unsoundness)** a
  name assigned on only one branch of an `if` ⇒ `\in_scope` is **withheld** (the false direction is
  NOT emitted) — a negative driver that *would* mis-prove under the old `keys()` snapshot;
  **`[PROVE]` (C)** after a dynamic `exec`, a `\in_scope(x)` that was decided-false beforehand is no
  longer decided-false.

## P4 — Metatype tags (EASY lookup + the (A)/(B) guards) (EASY–MEDIUM)

- **Tag constants** (§4.1) — flat int enum, sourced from Γ/`τ`/AST role. **No `TAG_BOOL`** — bool →
  `TAG_INT` (decision A).
- **`\typeof(x)` (Module4 → Module5):** read the tag from `τ`/AST role.
  - **(B) stable-`τ` guard:** decided to the tag **only if `x` has one consistent `τ` across all its
    assignments/paths** (reuse P3's per-name assignment scan); if `τ` differs across paths or `x` is
    retyped → **unknown**. Unknown also when `τ(x) = Any`.
  - contract-constrained: a `requires`/`ensures` `\typeof(x) == T` is assumed.
- **`\subtag` + `isinstance` rewrite (Module6):** `isinstance(x,T)` → `\subtag(\typeof(x), T)` (not
  `==`); `\subtag` reflexive + is-a edges (no `bool<:int` per A; every tag `<: object`; `method` NOT
  `<: function`); reduces to `==` for a **leaf** `T`, disjunction for a **base** `T`. `type(x) is T`
  → `==` **except** the bool case → Specified/unknown (decision A). Replaces the existing
  `isinstance_check`.
- **`__code__`** constants (`\code_argcount`/`\code_nlocals`) decided from the AST.
- **Drivers:** `[PROVE]` `isinstance` decided for `str`/`record`/`variant` operands; `[PROVE]` correct
  against a **base** type via `\subtag` (`isinstance(x, object)` true; the numeric-tower case);
  `[PROVE]` an `Any`-typed operand stays **symbolic**; **`[PROVE]` (B)** a local assigned `int` then
  `str` on different paths ⇒ `\typeof` is **unknown** (anti-unsoundness); **`[review]` (A)**
  `type(b) is bool` resolves to Specified/unknown, while `isinstance(b, int)` is decided-true.

## P5 — `exec` / `eval` (HARD)

- **`exec("literal")` (Module1):** detect `exec(Constant str)`; `ast.parse` the literal;
  **whitelist** = assignments + pure expressions only — **reject** `return`, `while`/`for` without an
  invariant, `import`, nested `def`/`class`, nested `exec`. Splice with line-number preservation;
  injected names enter via the P3 dataflow.
- **`eval("literal")`:** parse-and-resolve to a value + decided tag iff the expr's `τ` is concrete,
  else unknown.
- **Dynamic `exec`/`eval`:** `\trusted reviewer: dynamic-exec`; worst-case mutator that taints
  surrounding `assigns`/HAPPY (the non-exempt-`\trusted`-mutator rule) **and** the scope dataflow
  (decision C, wired in P3).
- **Drivers:** `[typecheck]` non-whitelisted inner code (a `return`, a loop sans invariant) is
  **rejected**; `[PROVE]` a spliced assignment's effect is visible after; `[review]` dynamic exec
  taints `assigns`/HAPPY and `\in_scope`.

## Order, gates, risks

**Order:** P0 (probe) → P1 (core+grammar) → P2 (easy wins) → P3 (dataflow) → P4 (tags) → P5 (exec) →
P6 (pure_lib). Each lands as its own gated PR; doc surfaces updated **in the same commit** (the new
keywords are `#@`/contract surface → doc-coherency gates them, unlike the seq model).

**Anti-unsoundness drivers are mandatory per phase** — every phase that can decide-false ships a
negative driver proving the *unsound direction is withheld* (the partial-info `\in_scope`, the
retyped `\typeof`, the post-dynamic-exec membership). This is the teeth of the three-valued
discipline; a phase without its negative driver is not done (Extreme Rigor).

**Risk register:**
- *Dataflow correctness (P3)* — Medium-Hard; the genuine new analysis. Mitigate with the
  partial-assignment negative driver.
- *`\subtag` SMT behaviour (P4)* — de-risked by P0.
- *exec splice (P5)* — Hard; conservative whitelist + reject-by-default keeps it fail-loud.
- *Scope of P6* — pure_lib is the other agent's domain for *existing* modules; the two **new**
  modules are in-scope here, but coordinate so they don't collide with concurrent stdlib work.

**Out of scope (per spec §12):** `MethodType`/closures; `exec` with literal globals/locals dicts;
value-level `SimpleNamespace`; closed-world `globals`/`hasattr`; a char/code-point model for
`__name__`; coroutine/generator behavioural modelling (tags only).
