# 07-1839-spec — Compile-time introspection & metatypes (scope, `types`, `exec`)

**Status:** Draft (generic specification — intent and gated phasing, not implementation)
**Date:** 2026-06-07 (rev. 2)
**Source:** synthesis of `introspect.md` (globals/locals/vars/exec) and `metatypes.md` (`types` via
type tags), with both design reviews folded in.
**Scope:** the **PyCSL tool** (`src/pycsl`: a dataflow pass + Module4/5 resolution + CSL grammar)
plus two pure_lib modules (`pure_lib/builtins`, `pure_lib/types_mod`). No semantic edits to existing
`pure_lib/`.
**Doctrine:** no-more-int / EXTREME RIGOR — model faithfully or defer honestly; **the only
acceptable failure mode is a loud one, never a wrong proof.** Files using no introspection emit
byte-identical WhyML (the regression gate).

**Revision 2 — corrected premise.** An earlier draft claimed *both* plans collapsed partial static
knowledge into decided facts, citing `metatypes`' "type tag from the annotation" as unsound because
"everything lowers to `int`." Per `docs/pycsl-static-semantics-reference.md` v1.3 that premise is
**wrong**: PyCSL has a *real, structured* type universe in the symbol table — `τ(str)=string`,
`τ(float)=real`, `τ(list)=array int`, `τ(dict)/τ(set)=map`, `τ(C)=record`, `τ(D)=variant` — and the
collapse to `int` happens only **at WhyML emission** (`module6_whyml/functions.py`), not in Γ.
So deriving a metatype tag from a value's `τ` is **sound**, and §1/§2/§4.2 are rewritten on that
basis. The genuinely unsound items were on the *scope* side (path-dependent assignment), which is
unaffected by the type model.

---

## 1. Unifying insight, and what is (and isn't) actually wrong

Both source plans rest on the same correct idea, preserved here: **PyCSL already possesses, at
verification time, the AST and symbol table that `globals()`/`locals()`/`vars()`/`type()`/`isinstance`
expose at runtime.** Introspection is therefore answered as *compile-time knowledge* — ghost
predicates and type tags resolved during analysis — and the runtime dict / type-object never appears
in WhyML (the `sizeof()`-as-compile-time-constant analogy).

The earlier synthesis over-criticised. With PyCSL's **real type universe** (Γ distinguishes
`string` / `real` / `list` / `dict` / `record` / `variant` / `int`; the `int`-collapse is an
*emission* detail), the two plans are **not** symmetric in their soundness:

- **`metatypes` is sound where it derives a metatype from `τ`.** A `str` parameter is a `string`, a
  `MyClass` parameter is a `record`, a `#@ datatype` value is a `variant` — these are statically
  distinguished in Γ exactly as `\valid`'s list-typing already keys off `τ(Γ_f(arr)) ∈ {list, …}`.
  Tag-from-annotation is therefore legitimate, **not** a guess. (Retraction of the earlier claim.)

- **`introspect` is genuinely unsound on the scope side**, independent of any type model. Scope
  *membership* is path-dependent — conditional assignment, `del`, and `exec`-injected names mean a
  `keys()`-snapshot of `locals()` and a decided-`false` `hasattr` can certify facts that fail on some
  execution path. This is a real bug and the reason a dataflow analysis (not a snapshot) is required.

So the three-valued resolution discipline (§2) is retained, but its *weight* differs per side:

1. **Scope side — the substantive fix.** Membership is path-dependent → definite-assignment dataflow.
2. **Metatype side — a thin boundary guard.** `\typeof` is *decided* for any value with a concrete
   `τ` (the common case); the *only* unknown tail is `τ = Any` (an unannotated parameter, or an
   unresolved class/import that the reference notes "still coarsens to `int`").
3. **An independent representational point (survives, model-agnostic).** `isinstance` against a
   *base/abstract* type needs a subtype relation, not tag equality — `bool` has its own tag but
   `isinstance(True, int)` must be true. Hence `\subtag`, not `==` (§4.2).

## 2. The three-valued resolution discipline (the spine)

Every introspection query resolves to one of:

- **decided-true** — static information is *complete* in the affirmative direction; emit a proven fact.
- **decided-false** — static information is *complete* in the negative direction; emit a proven negation.
- **unknown** — information is partial; emit **nothing decided** (free symbolic value, or `\trusted`).
  Never `true`, never `false`.

What produces "decided" differs by side, reflecting §1:

- **Scope membership → definite-assignment dataflow.** A name is decided-true only if assigned on
  **all** paths to the program point, decided-false only if assignable on **no** path, else unknown.
  (Replaces `introspect`'s `keys()` snapshot — the genuine unsoundness.) This is a *new analysis*.

- **Metatype tag → the symbol table's `τ` (and AST role).** `\typeof(x)` is **decided** to the
  τ-tag whenever `x` has a concrete `τ` in Γ (`string`/`real`/`list`/`dict`/`record`/`variant`/`int`),
  or to an AST-role tag when `x` is bound to a `FunctionDef` / `import` / `ClassDef`. It is **unknown
  only when `τ(x) = Any`** (unannotated parameter, unresolved class/import). This is mostly a *table
  lookup*, not a new analysis — and it is sound because Γ's `τ` is already sound (the reference's
  `τ(str)=string`, `τ(float)=real` fixes; the `int`-collapse is downstream of Γ).

**Fail-safe property (the reason this is sound).** Under-determination is *safe*: an unknown query
yields no usable fact, so a proof may fail to go through but is never wrong. The *only* unsound
outcome is a wrong "decided." On the scope side that is prevented by the conservative all-paths /
no-path dataflow; on the metatype side it is inherited directly from `τ` being sound (a value tagged
`string` genuinely is a `string`). The worst case is a missing proof or a `\trusted`, never a false
theorem — the same fail-safe stance as the seq-model and HAPPY work.

## 3. Part A — Scope introspection (`globals`, `locals`, `vars`)

*(Unchanged — the scope side is independent of the type model.)*

### 3.1 `globals()` — sound **lower bound** (open world)
Module-level bindings are statically enumerable (`collect_module_globals`), but the world is **open**
— `import` and `exec` can inject names. `\in_globals(name)` is decided-true for a statically declared
module name, and **unknown (not decided-false)** otherwise unless a closed-world assumption is
explicitly asserted. Ghost predicate; no runtime dict.

### 3.2 `locals()` — definite-assignment, three-valued
`\in_scope(name)` is decided-true only when `name` is assigned on **all** paths to the call site,
decided-false only when it is assignable on **no** path, else unknown. `del x`, conditional
assignment, and `exec`-injected names (§5) are exactly why the old `keys()` snapshot was unsound.
`\scope_type(name)` returns the type (its `τ`) only when membership is decided-true.

### 3.3 `vars(obj)` — lower bound only
Per the reference, Γ_c collects `self.field` from `__init__` (§1.2). The analysis additionally scans
other methods that assign `self.f`. `\has_attr(obj, name)` is therefore a sound **lower bound**:
decided-true for a field assigned on all paths through the relevant constructor/method, **unknown
(not decided-false)** otherwise — `hasattr` returning a hard `false` is the unsound direction.

## 4. Part B — Metatypes (`types` via type tags)

### 4.1 Tag constants and their source
A flat integer enum names each metatype; the constants themselves are trivial. What matters is that
each tag has a **sound static source**, drawn from PyCSL's existing classification:

| Tag | Source in Γ / AST |
|---|---|
| `TAG_INT` | `τ(x) = int` (incl. `bool`, which is `τ(bool)=int`) |
| `TAG_STR` | `τ(x) = string` |
| `TAG_FLOAT` | `τ(x) = real` |
| `TAG_LIST` | `τ(x) = list` (`array int`) |
| `TAG_DICT` / `TAG_SET` | `τ(x) = dict` (`map`) |
| `TAG_CLASS`-of-`C` / record | `τ(x) = record` (registered class `C`) |
| `TAG_VARIANT`-of-`D` | `τ(x) = variant` (`#@ datatype D`) |
| `TAG_FUNCTION` / `TAG_LAMBDA` | name bound to a `FunctionDef` / lambda |
| `TAG_MODULE` | name bound to an `import` |
| `TAG_METHOD`, `TAG_GENERATOR`, `TAG_CODE`, … | AST role (method, `yield`-function, `__code__`) |

`TAG_LAMBDA = TAG_FUNCTION` (a lambda *is* a function). SMT handles tag equality/distinctness
trivially. The enum is sound precisely because every row reads an already-sound Γ/`τ` fact.

### 4.2 `\typeof(x)` and `isinstance` — Γ-derived, three-valued only at the `Any` tail

`\typeof(x)` is read from Γ:

- **decided** — `x` has a concrete `τ` (any §4.1 row) or a known AST role → its tag. This is the
  common case and is **sound**, because Γ's `τ` is sound. The fact that several tags later collapse
  to `int` *at WhyML emission* does **not** erase the tag: `\typeof` reads the symbol-table `τ`, not
  the lowered representation. (This is the explicit retraction of the earlier "tag-from-annotation is
  unsound" claim — it is sound.)
- **contract-constrained** — a `requires`/`ensures` asserts `\typeof(x) == T`; assume it.
- **unknown** — **only** when `τ(x) = Any` (unannotated parameter, unresolved class/import). Then
  `\typeof(x)` is a free symbolic tag, constrained only by contracts; `isinstance`/`type` on such a
  value stays symbolic, never decided-false.

`isinstance(x, T)` lowers to **`\subtag(\typeof(x), T)`**, not `\typeof(x) == T` — an
*independent* point that holds regardless of the type model. `\subtag` is reflexive plus the real
is-a edges (`bool <: int`, every tag `<: object`, `method`/`function` `<:` *callable* as a relation;
note `method` is **not** `<: function`, so `isinstance(aMethod, FunctionType)` is correctly `false`).
`\subtag(a, T)` **reduces to `a == T`** exactly when `T` is a **leaf** type with no subtypes — which
is the common concrete `types.*Type` case `metatypes` got right — and becomes a disjunction over
sub-tags when `T` is a **base/abstract** type (`object`, the numeric tower), the case raw `==` got
silently wrong. `type(x) is T` (exact identity) still lowers to `==`.

Resolution: decided-true/false when `\typeof(x)` is decided (or a constraint contradicts the check);
**symbolic only at the `Any` tail.**

### 4.3 `__code__` static constants (sound)
`co_argcount`, `co_nlocals`, etc. are genuine compile-time facts; emit per-function ghost constants
(`\code_argcount(f)`, `\code_nlocals(f)`) decided from the AST.

### 4.4 `__name__` and `getsizeof` — **Specified**, not resolved
`\attr_name(x)` as *string length* is a Specified approximation (no character/code-point type, per
the reference's string-model limitations — two equal-length names are indistinguishable). `getsizeof`
is value/implementation-dependent — Specified (TCB), never a "known constant." Both → the Soundness
Ledger (§8).

### 4.5 `SimpleNamespace` — honest **size model**
Tracks attribute *count*, not values (no value-level field tracking without per-key map content):
`set_attr` increments, `get_attr` requires non-empty. Stated as size-only.

## 5. Part C — `exec` / `eval`

*(Unchanged.)*

### 5.1 `exec("literal")` — whitelisted splice
Parse the literal with `ast.parse`, splice with line-number preservation. The gate is **not** merely
"no contracts": the spliced AST must be a **whitelisted, contract-free, control-flow-local**
statement set — **assignments and pure expressions only.** `return`, `while`/`for` without an
invariant, `import`, nested `def`/`class`, and nested `exec` are **rejected**. Names introduced enter
scope via the §3.2 dataflow, not as a snapshot.

### 5.2 `eval("literal")` — expression form
Same parse-and-resolve; yields a value plus a decided tag when the expression's `τ` is concrete, else
unknown.

### 5.3 Dynamic `exec`/`eval` — **tainting `\trusted`**
A computed (non-literal) string is the halting problem; mark `\trusted reviewer: dynamic-exec`. It is
**not** a no-op: it can write anything, so any surrounding `assigns` / HAPPY confinement must treat it
as a **worst-case mutator** (the same rule the reference applies to a non-exempt `\trusted`/`\abstract`
mutator without `#@ \preserves`). It taints integrity claims in its scope.

### 5.4 Dropped from v1
`exec` with literal globals/locals **dicts** (introspect §2.2) — synthesizing a scope and propagating
assignments back is high-risk scope surgery; out of scope here.

## 6. Contract-language extensions (all verification-time, zero runtime cost)

| Predicate | Meaning | Resolution |
|---|---|---|
| `\in_scope(name)` | name in current locals | definite-assignment, 3-valued (§3.2) |
| `\in_globals(name)` | name is a module binding | lower bound; true-only (§3.1) |
| `\has_attr(obj, name)` | obj's class declares field | lower bound; true-only (§3.3) |
| `\scope_type(name)` | static `τ` of name | when membership decided-true |
| `\typeof(x)` | metatype tag | Γ-derived; unknown only at `Any` (§4.2) |
| `\subtag(a, T)` | a is-a T | reflexive + is-a edges; `==` iff T leaf |
| `\is_callable(x)` | x callable | `\subtag(\typeof(x), callable)` |
| `\code_argcount(f)` / `\code_nlocals(f)` | code facts | decided from AST (§4.3) |

## 7. Builtins (consolidated, conditional labels)

| Builtin | Strategy | Bucket / condition |
|---|---|---|
| `globals()` | ghost lower-bound map (§3.1) | sound (true-only) |
| `locals()` | definite-assignment (§3.2) | sound (3-valued) |
| `vars(obj)` | class-field lower bound (§3.3) | sound (true-only) |
| `type(x)` | Γ-derived tag (§4.2) | **decided for concrete τ**; symbolic at `Any` |
| `isinstance(x,T)` | `\subtag(\typeof(x),T)` (§4.2) | decided for concrete τ; symbolic at `Any` |
| `hasattr(o,n)`/`getattr(o,n)` | literal n → field; lower bound | conditional |
| `abs`,`divmod`,`pow`,`round`,`min`,`max`,`sum` | pure arithmetic | **Modelled**, trivial |
| `len` | `\length` (existing) | Modelled |
| `getsizeof` | Specified (§4.4) | **TCB** |
| `print`/`input`/`open` | World I/O (`assigns world.stdout/stdin/fs`) | Modelled (World) |
| `exec`/`eval` | §5 (literal splice / dynamic `\trusted`) | conditional / **TCB** |

## 8. Soundness Ledger (TCB)

| Entry | What is trusted/approximated |
|---|---|
| dynamic `exec`/`eval` | worst-case `\trusted` mutator; taints surrounding confinement (§5.3) |
| `getsizeof` | value-dependent size; specified constant |
| `__name__` as length | name strings indistinguishable by content (no char type, per reference) |
| `SimpleNamespace` | attribute *count* only, not values |
| `new_class`/`prepare_class`/`coroutine` | factory stubs: `\typeof(\result)==TAG_CLASS` etc. proven for the *caller*; class creation unmodelled |
| `\in_globals` / `\has_attr` decided-false | **not** emitted (open world) — soundness preserved by refusing the false direction |

Note: `\typeof` from `τ` is **not** a ledger entry — it is decided from sound symbol-table type
information, not assumed. A `--soundness-report` should list which proven VCs rest on the rows above.

|---|---|---|
| **P1 — 3-valued core** | decided/decided/unknown infra + ghost-predicate grammar (§6) | **[review]** unknown never emitted as a fact |

## 11. Difficulty (re-rated honestly)

| Component | Difficulty | Note |
|---|---|---|
| Tag constants, arithmetic builtins | **Trivial/Easy** | sound as-is |
| `\typeof` from `τ` / AST role | **Easy** | a symbol-table lookup — Γ already carries the distinguishing tag (corrected: *not* a new classification) |
| `globals()` lower bound, `type()` on concrete τ | **Easy** | with the 3-valued guard |
| `\subtag` relation + `isinstance` rewrite | **Medium** | the base-type fix (model-independent) |
| Definite-assignment dataflow (`locals`/`has_attr`) | **Medium-Hard** | a real pass — the genuine scope-side fix, *not* "already exists" |
| `exec("literal")` whitelist splice | **Hard** | control-flow-local statement set |
| dynamic `exec`/`eval`, `getsizeof` | **`\trusted`/Specified** | TCB, honest |
| `MethodType(func,obj)` binding | **Deferred** | needs a closure/binding model PyCSL lacks |

## 12. Out of scope

`MethodType(func,obj)` and any closure/binding model; `exec` with literal globals/locals dicts;
value-level `SimpleNamespace` (needs per-key map content); closed-world `globals`/`hasattr` (the
decided-false direction); a character/code-point model for names (length approximation only, per the
reference's string limitations); `pure_lib/` semantic edits beyond the two new modules;
coroutine/generator *behavioural* modelling (tags only).

> **In one line (corrected):** both plans rightly treat introspection as compile-time knowledge to
> *expose*; the real unsoundness was on the **scope** side — path-dependent membership demands
> definite-assignment dataflow, not a snapshot — while `metatypes`' tag-from-annotation is **sound**
> given PyCSL's real type universe (`str`/`float`/`list`/`record`/`variant` are statically
> distinguished, the `int`-collapse being only an emission detail). The three-valued discipline is
> kept, but on the metatype side it guards only the thin `Any`/unresolved tail, plus the
> model-independent need for `\subtag` over `==` on base types.
